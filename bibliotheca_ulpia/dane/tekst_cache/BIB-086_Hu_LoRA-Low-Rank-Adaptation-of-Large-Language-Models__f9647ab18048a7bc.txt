Fig. 1. Model Architecture of LoRA-Enhanced RT-DETR. Our model integrates LoRA with rank r = 16 into the AIFI module and deformable transformer to enable
efficient fine-tuning. The backbone first extracts multiscale features from the input ultrasound image, which are then processed by the Attention-based Intra-scale
Feature Interaction (AIFI) module (left box) to perform cross-scale feature fusion and IoU-aware query selection. Next, the Deformable Transformer (right box)
refines these query features before producing final object predictions via score and bounding-box heads. LoRA components (shown in yellow) are inserted into critical
linear layers of both the AIFI and Deformable Transformer, enabling a low-rank, parameter-efficient adaptation without retraining the entire model. The bottom
panels detail how LoRA is injected into feed-forward and cross-attention layers, freezing the original weights while learning small low-rank updates.
