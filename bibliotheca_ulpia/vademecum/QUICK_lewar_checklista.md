# ⚡ VADEMECUM — Checklista przed wejściem na lewarze

> Jedna strona. Przeczytaj PRZED każdym wejściem. Pełna wiedza → `encyklopedia/LEW_futury_i_lewar.md`.

## ✅ PRZED WEJŚCIEM (zero wyjątków)
- [ ] Policzona **cena likwidacji** — czy jest dalej niż mój SL? (jeśli nie → lewar za wysoki)
- [ ] **Rozmiar z ryzyka, nie z lewara:** `pozycja = (kapitał × %ryzyka) / dystans_do_SL`
- [ ] Ryzyko na transakcję ≤ **1-2%** konta
- [ ] **Wyższy TF zgodny** z kierunkiem? (MTF konfluencja — inaczej wchodzę pod nóż)
- [ ] **Funding** nie skrajny przeciw mnie? (drogi long przy +0.1%/8h)
- [ ] SL **nie na okrągłej liczbie** (stop hunt)
- [ ] Reżim zmienności (GARCH) — wysoki? → lewar/pozycja **w dół**

## 🚫 STOP — NIE WCHODŹ jeśli:
- chcę „odrobić" stratę (revenge) → HALT
- lewar >20× bez konkretnego powodu scalpowego
- brak SL „bo wróci"
- seria strat ≥ próg Reguły 6% → konto w HALT

## 📏 SZYBKIE LIQ (isolated, long, MMR~0.5%)
| Lewar | Spadek do likwidacji |
|-------|----------------------|
| 3× | ~33% |
| 5× | ~19% |
| 10× | ~9.5% |
| 20× | ~4.5% |
| 50× | ~1.5% (ruletka) |

## 🎯 LEWAR DO STYLU
- Scalp (min-godz): 10-20×, SL ciasny
- Swing (dni): 3-5×, SL 2-5%
- Pozycja (tyg+): 1-2× / spot
