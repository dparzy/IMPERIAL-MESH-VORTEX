# 📥 Wrzutnia — skrytka na materiały do analizy

Miejsce, gdzie Cezar wrzuca **cokolwiek** do przeanalizowania: pomysły, raporty,
zrzuty ekranu, PDF-y, wycinki z artykułów, surowe CSV, notatki na kolanie.
Bez porządku, bez ceremonii — od tego jest ten folder.

## Zasady

- **Wszystko tutaj jest LOKALNE.** Git ignoruje całą zawartość (poza tym README
  i `.gitignore`). Wrzucone pliki zostają na Twojej maszynie — nie wchodzą do repo,
  nie synchronizują się na laptop, nie brudzą drzewa, nie blokują auto-pull.
  (Ta sama zasada co `dane/` i `raporty/` — lekcja o brudnym drzewie z `.gitignore`.)
- **Nic się stąd samo nie usuwa.** Claude nie kasuje plików z wrzutni bez Twojego
  wyraźnego polecenia (Prawo XVIII: kasowanie danych, których nie utworzył = pytanie).
- **Chcesz, żebym coś przeanalizował?** Powiedz „zobacz plik w wrzutni: <nazwa>"
  albo po prostu „przeanalizuj wrzutnię" — przejrzę zawartość i zaraportuję.

## Jak to działa

Możesz wrzucać pliki:
- przez eksplorator Windows do `C:\Projekty\imperial-mesh-vortex\wrzutnia\`,
- przeciągnięciem, kopiuj-wklej, zapisem z przeglądarki — obojętnie.

Podfoldery są dozwolone (np. `wrzutnia/2026-07/`, `wrzutnia/pomysly/`) — też lokalne.

## Czego TU nie trzymać

- Rzeczy, które mają trafić do Imperium na stałe → idą do `docs/`, `imperium/`,
  `bibliotheca_ulpia/` (wersjonowane, z opisem wg Zasady Pełnego Opisu).
- Duże binaria bibliotek (BIB-*) → Cezar wrzuca je swoją ścieżką (osobna zasada).

Wrzutnia to **poczekalnia**, nie magazyn: materiał wpada tu surowy, a wnioski
z niego lądują tam, gdzie ich miejsce (lekcja do pamięci, moduł do kodu, wpis do docs).
